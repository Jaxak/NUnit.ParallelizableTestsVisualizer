# NUnit.ParallelizableTestsVisualizer
Генерирует схему для анализа параллельного выполнения тестов. Позволяет найти слабые места и оптимизировать.

## Описание
Инструмент для визуализации параллельного выполнения NUnit тестов. Показывает временную диаграмму выполнения тестов на разных потоках, помогая выявить узкие места и оптимизировать время выполнения тестового набора.
